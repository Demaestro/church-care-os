# Premium UI/UX Design System

## Visual Language

- Minimal, editorial, premium
- High contrast type hierarchy
- Calm neutral palette with warm accents
- Generous whitespace and rhythm

## Performance Targets

- First interaction on 3G under 4s
- Critical UI shell cached at edge
- Optimistic UI for actions

## Components

- Top navigation with focus‑ready dropdowns
- Command bar for fast access
- Status badges for care urgency
- Timeline and follow‑up cards
