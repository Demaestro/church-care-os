# AI Agent Layer ("Digital Deacon")

This layer adds AI‑assisted workflows without exposing raw sensitive data.

## Agents

- Proactive Care Agent
  - Detects lapsed engagement patterns
  - Suggests follow‑up cadence
- Financial Auditor Agent
  - Reconciles bank feeds to ledger
  - Flags anomalies and unbalanced entries
- Secretary Agent
  - Summarizes meetings
  - Drafts church‑voice communications

## Safety Constraints

- Tool calling allowlist only
- No raw pastoral notes unless elevated permission
- All AI access logged
- Tenant isolation per church
